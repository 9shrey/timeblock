Troubleshooting

Solutions to common problems when installing or running Timeblock.

macOS: "Timeblock can't be opened"

Timeblock isn't notarized by Apple yet, so macOS blocks the first launch.

  1. Try to open Timeblock once and dismiss the warning.
  2. Open System Settings → Privacy & Security.
  3. Scroll down and click Open Anyway next to the message about Timeblock.

You only need to do this once.

Windows: SmartScreen warning

Windows may show "Windows protected your PC" because the installer isn't code-signed. Click More info, then Run anyway.

Linux: the AppImage doesn't start

The AppImage needs glibc 2.39 or newer (Fedora 40+, Ubuntu 24.04+). On older systems, install the .rpm or .deb package instead. Make sure the file is executable:

chmod +x Timeblock_*.AppImage

Linux: blank or flickering window

WebKitGTK, which Timeblock uses to draw its window on Linux, doesn't always work well with the proprietary NVIDIA driver, especially on Wayland. Timeblock already sets WEBKIT_DISABLE_DMABUF_RENDERER=1 when the NVIDIA kernel module is loaded (unless you set it yourself).

If the window is still blank or flickers, start Timeblock from a terminal with one of these, trying them one at a time:

WEBKIT_DISABLE_COMPOSITING_MODE=1 timeblock
__NV_DISABLE_EXPLICIT_SYNC=1 timeblock
GDK_BACKEND=x11 timeblock

Once you find one that works, add it to the Exec= line of Timeblock's desktop entry, for example with env WEBKIT_DISABLE_COMPOSITING_MODE=1 timeblock.

A second launch doesn't open a new window

This is intentional. Only one copy of Timeblock runs at a time so that two windows can't write to the same database. Launching it again brings the open window to the front.

An error says a change could not be saved

If a save fails, Timeblock reloads your data from disk and discards the changes that were waiting behind the failed save. Check that the disk isn't full and that the data folder is writable. Your backups are not affected.

Reporting a problem

If none of this helps, open an issue on GitHub. Include your operating system and version, how you installed Timeblock, and what you see. The app version is shown at the bottom of Settings.

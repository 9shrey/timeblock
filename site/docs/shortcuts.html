Keyboard shortcuts

Every common action has a shortcut. On macOS, use ⌘ in place of Ctrl.

Navigation

KeysAction
dDay view
wWeek view
gGoals
rReview
tGo to today
[ / ]Previous / next day or week
Ctrl+BShow or hide the week budget panel

Selected block

KeysAction
EnterEdit the selected block
DeleteDelete the selected block (skips a ghost)
↑ / ↓Move the block earlier or later
Shift+↑ / Shift+↓Make the block shorter or longer
1–9Set the block's goal
EscCancel a drag, close the editor, or clear the selection

Logging

KeysAction
aConfirm the selected plan block or ghost as happened
sSkip the selected plan block or ghost
Shift+AConfirm the rest of the day as planned

Editing

KeysAction
Ctrl+ZUndo
Ctrl+Shift+ZRedo

Mouse modifiers

KeysAction
Shift + dragSnap to 5 minutes
Ctrl + dragCopy the block instead of moving it
Double-clickCreate a block of the default length
Right-clickOpen the context menu

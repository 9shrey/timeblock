macOS

Your system

Universal (Apple silicon and Intel)

  • .dmgDisk image

Open the .dmg and drag Timeblock to Applications. The app isn't notarized yet, so the first launch is blocked: open System Settings → Privacy & Security and click Open Anyway.

Windows

Your system

Windows 10 and 11, 64-bit

  • .exeInstaller
  • .msiWindows Installer package

If SmartScreen warns about an unrecognized app, click More info → Run anyway.

About unsigned builds. Timeblock builds are not code-signed yet, which is why macOS and Windows show a warning on first launch. Every build is produced by a public GitHub Actions workflow from the tagged source code.

Build from source

You need Node 22+, stable Rust and the Tauri system dependencies.

git clone https://github.com/9shrey/timeblock.git
cd timeblock
npm install
npm run tauri build

Bundles are written to src-tauri/target/release/bundle/.
